# SideNote 개인정보 처리방침

최종 수정일: 2026-09-10

SideNote(이하 "확장")는 Chrome 탭에서 재생 중인 강의 오디오를 자막으로 만들고, 메모와 화면 캡처를
함께 저장해 주는 Chrome 확장 프로그램입니다.

## 한 줄 요약

**SideNote 는 어떤 데이터도 수집하지 않고, 어디로도 전송하지 않습니다.** 만들어진 자막·메모·캡처는
전부 사용자의 컴퓨터 안에만 저장됩니다. 계정도, 로그인도, 결제도, 광고도 없습니다.

## 확장이 다루는 데이터

| 데이터 | 어디서 오는가 | 어디에 저장되는가 | 외부 전송 |
| --- | --- | --- | --- |
| 탭 오디오 | 사용자가 [자막 시작] 을 눌렀을 때의 현재 탭 | 저장하지 않음(인식 즉시 폐기) | 없음 |
| 자막 텍스트 | 위 오디오의 음성 인식 결과 | 브라우저 로컬 저장소(IndexedDB) | 없음 |
| 메모 | 사용자가 직접 입력 | 브라우저 로컬 저장소(IndexedDB) | 없음 |
| 화면 캡처 이미지 | 사용자가 [캡처] 를 눌렀을 때의 현재 탭 화면 | 브라우저 로컬 저장소(IndexedDB) | 없음 |
| 페이지 제목·주소·영상 재생 위치 | 현재 탭 | 캡처/자막에 붙는 메모 정보로 로컬 저장 | 없음 |
| 자막 번역문 | 위 자막을 Chrome 내장 번역기가 옮긴 결과 | 브라우저 로컬 저장소(IndexedDB) | 없음 |
| 설정(자막 언어, 번역 언어 등) | 사용자 선택 | `chrome.storage.local` | 없음 |

## 음성 인식은 어디서 이루어지나

**Chrome 에 내장된 기기 내(on-device) 음성 인식 한 가지만** 사용하며, 인식은 사용자의 컴퓨터 안에서
이루어집니다. 확장은 `processLocally: true` 로만 요청하므로 네트워크로 오디오를 보내는 인식 경로는
사용하지 않습니다. 언어팩은 Chrome 이 Google 로부터 내려받는데, 이는 Chrome 자체의 동작이며
그 과정에서 확장이 오디오나 자막을 보내는 일은 없습니다.

## 번역은 어디서 이루어지나

번역을 켰을 때는 **Chrome 에 내장된 번역기(Translator API)** 만 사용하며, 번역도 사용자의 컴퓨터 안에서
이루어집니다. 확장은 번역할 문장을 외부로 보내지 않습니다. 언어 조합에 필요한 번역 모델은 Chrome 이
내려받는데, 이는 음성 언어팩과 마찬가지로 Chrome 자체의 동작입니다. 번역을 끄면(기본값) 번역기는
아예 만들어지지 않습니다.

확장은 외부 프로그램이나 별도 서버와 통신하지 않습니다. 네트워크로 나가는 요청 자체가 없습니다.

## 확장이 하지 않는 것

- 개인정보(이름, 이메일, 주소, 신원 정보) 수집
- 건강·금융 정보 수집
- 인증 정보(비밀번호, 쿠키, 토큰) 수집
- 위치 정보 수집
- 웹 열람 기록(방문한 사이트 목록) 수집
- 사용자 활동 추적, 분석 도구(Analytics) 탑재
- 데이터의 판매·양도·제3자 제공
- 확장의 핵심 기능과 무관한 용도로의 데이터 사용

## 권한을 요구하는 이유

- `tabCapture` — 현재 탭에서 나는 소리를 받아 자막으로 만들기 위해. 사용자가 [자막 시작] 을 누른 탭에만 적용됩니다.
- `offscreen` — Manifest V3 에서 오디오 처리를 수행할 수 있는 문서를 띄우기 위해. 오디오는 이 문서 안에서만 처리되고 저장되지 않습니다.
- `sidePanel` — 자막·메모·캡처를 오른쪽 패널에 표시하기 위해.
- `storage` — 사용자의 설정(자막 언어, 번역 언어)과 세션 목록을 이 컴퓨터에 저장하기 위해.
- `activeTab`, `tabs` — 자막·캡처의 대상이 되는 탭을 식별하고, 탭이 닫히거나 주소가 바뀌면 녹음을 정리하기 위해.
- `scripting` — 재생 중인 `<video>` 의 화면상 위치와 재생 위치를 읽어 캡처를 영상 영역으로 잘라내고, 원할 때 영상 위에 자막을 겹쳐 보여주기 위해.
- `host_permissions` (`http://*/*`, `https://*/*`) — 어떤 강의 사이트에서든 위 두 가지(영상 위치 확인, 화면 캡처)가 동작해야 하기 때문입니다. 페이지 내용을 읽어 저장하거나 전송하지 않습니다.

## 데이터 삭제

패널의 [기록] 목록에서 개별 노트를 삭제하거나, [현재 자막 지우기] 로 지금 노트의 자막만 지울 수
있습니다. Chrome 에서 확장을 삭제하면 저장된 자막·메모·캡처가 모두 함께 제거됩니다.
별도로 서버에 남는 사본은 없습니다.
