# Chrome 웹스토어 등록 정보 (SideNote)

Developer Dashboard 의 각 칸에 **그대로 복사해 붙여 넣는** 원고입니다.
칸 이름은 대시보드에 보이는 한국어 라벨 기준입니다.

---

## 1. 스토어 등록정보 탭

### 이름 (최대 75자)
```
SideNote
```

### 간단한 설명 (최대 132자)
```
강의 탭의 소리를 이 컴퓨터 안에서 실시간 자막으로 만들고, 메모와 화면 캡처를 사이드패널에 함께 모아 두는 학습 노트입니다.
```

### 자세한 설명
```
SideNote 는 온라인 강의를 들으면서 자막·메모·화면 캡처를 한자리에 모으는 학습 노트입니다.

■ 실시간 자막
현재 보고 있는 탭의 소리를 그대로 받아 자막으로 만듭니다. 시작·일시정지·재개·정지를 직접 제어할 수 있고,
자막은 아래로 쌓이면서 자동으로 따라 내려갑니다. 위로 올려 지난 내용을 읽는 중에는 자동 스크롤이 멈추고,
다시 맨 아래로 내려가면 따라가기가 돌아옵니다. 전체 자막을 한 번에 복사할 수 있습니다.

■ 영상 위 자막
원하면 자막을 영상 위에 겹쳐서, 유튜브 자막처럼 보면서 들을 수 있습니다.

■ 캡처 + 그 순간의 메모
[캡처] 를 누르면 지금 보고 있는 화면이 저장됩니다. 재생 중인 영상이 있으면 그 영상 영역으로 잘라 주고,
영상의 재생 위치(예: 12:34)도 함께 남깁니다. 캡처마다 메모를 달 수 있어서 "이 장면에 대한 내 생각" 이
따로 놀지 않습니다. 강의 전체에 대한 일반 메모는 자동 저장됩니다.

■ 영상마다 노트가 따로
다른 영상으로 넘어가면 자막이 자동으로 새로 시작됩니다. 한 화면에 이전 영상 자막이 섞이지 않고,
이전 영상의 자막·메모·캡처는 [기록] 에 그대로 남아 언제든 다시 열어볼 수 있습니다.

■ 다시 열어도 그대로
브라우저를 새로고침하거나 사이드패널을 닫았다 열어도 자막·메모·캡처가 그대로 남아 있습니다.
같은 강의 페이지로 돌아오면 그 노트를 이어서 씁니다.

■ 인터넷으로 나가지 않습니다
음성 인식은 Chrome 에 내장된 기기 내(on-device) 인식으로 이 컴퓨터 안에서 처리됩니다.
오디오도, 자막도, 메모도, 캡처도 외부로 전송되지 않습니다. 계정도 로그인도 결제도 광고도 없습니다.

■ 이런 분께
· 인강·MOOC·강연 영상을 들으며 필기하는 분
· 자막 없는 강의 영상을 텍스트로 남기고 싶은 분
· 캡처와 메모가 폴더 여기저기 흩어져 곤란했던 분

■ 사용법
1) 강의 영상을 재생합니다.
2) 그 탭에서 SideNote 아이콘을 누릅니다. 오른쪽에 패널이 열립니다.
3) [자막 시작] 을 누릅니다. Chrome 이 탭 소리 공유를 물으면 허용합니다.

■ 참고
· 첫 실행 때 Chrome 이 음성 인식 언어팩을 내려받는 동안 잠시 기다려야 할 수 있습니다.
· 자막은 자동 인식 결과이므로 100% 정확하지 않습니다. 학습 보조용으로 사용해 주세요.
· 소리가 나지 않는 탭이나 chrome:// 페이지에서는 자막을 만들 수 없습니다.
· Chrome 139 이상이 필요합니다. (기기 안에서 음성 인식을 하는 기능이 그 버전부터 제공됩니다.)
```

### 카테고리
```
업무 효율 (Productivity)  →  하위: 워크플로 및 계획 (Workflow & Planning)
```

### 언어
```
한국어
```

### 스토어 아이콘 (128x128)
```
brand/sidenote-icon-128.png  (없으면 apps/extension/public/icons/icon-128.png 를 그대로 올려도 됩니다)
```

### 스크린샷 (1280x800 PNG, 최소 1장 / 권장 4~5장)
직접 찍어야 합니다. 아래 4장이면 심사와 설명 둘 다 충분합니다.

| # | 무엇을 담나 | 찍는 법 |
| --- | --- | --- |
| 1 | 강의 영상 + 오른쪽에 자막이 쌓인 패널 | 유튜브 강의 재생 → 아이콘 클릭 → [자막 시작] → 자막 20줄쯤 쌓였을 때 `Shift+Cmd+4` 후 `Space` 로 창 전체 촬영 |
| 2 | 캡처 카드 + 그 캡처에 단 메모 | 패널에서 [캡처] → 메모 입력 → 카드가 보이게 촬영 |
| 3 | 영상 위 자막 켠 화면 | 패널에서 [영상 위 자막] 켜기 → 영상 아래에 자막이 깔린 상태로 촬영 |
| 4 | 기록 목록 | 패널 위쪽 [기록 ▾] 을 눌러 지난 노트 목록이 보이는 상태로 촬영 |

찍은 뒤 크기를 1280x800 으로 맞춥니다:
```
sips -s format png -z 800 1280 ~/Desktop/shot1.png --out store/screenshots/1.png
```
(비율이 다르면 여백이 생기므로, 촬영 시 창을 16:10 에 가깝게 두면 깔끔합니다.)

### 프로모션 이미지
선택 사항입니다. 넣고 싶으면 440x280 "작은 프로모션 타일" 한 장만 만들면 됩니다.

## 2. 개인정보 보호 탭 (Privacy practices)

### 단일 목적 설명 (Single purpose)
```
현재 Chrome 탭에서 재생 중인 강의 영상의 소리를 기기 내에서 자막으로 만들고, 그 자막과 사용자가 남긴 메모·화면 캡처를 사이드패널 한곳에 모아 학습 노트로 저장하는 것이 이 확장의 유일한 목적입니다.
```

### 권한별 사유 (각 칸에 그대로 붙여 넣기)

**tabCapture**
```
사용자가 [자막 시작] 을 누른 탭의 오디오를 받아 자막으로 변환하기 위해 필요합니다. 이 확장의 핵심 기능이며, 사용자가 명시적으로 시작한 탭에만 적용되고 정지하면 즉시 해제됩니다. 캡처한 오디오는 저장하지 않고 인식 직후 폐기하며 외부로 전송하지 않습니다.
```

**offscreen**
```
Manifest V3 의 서비스 워커에서는 오디오 처리와 음성 인식 API 를 사용할 수 없어, 오디오를 처리할 오프스크린 문서가 필요합니다. 이 문서는 자막이 켜져 있는 동안에만 존재하고 정지하면 닫힙니다.
```

**sidePanel**
```
자막, 메모, 화면 캡처를 강의 영상을 가리지 않고 나란히 보여주기 위해 Chrome 사이드패널을 사용합니다.
```

**storage**
```
자막 언어 같은 설정과 현재 세션 식별자를 이 컴퓨터에 저장하기 위해 사용합니다. 외부로 동기화하거나 전송하지 않습니다.
```

**activeTab**
```
사용자가 확장 아이콘을 눌러 사이드패널을 연 그 탭을 자막·캡처 대상으로 특정하기 위해 사용합니다.
```

**tabs**
```
자막을 만들고 있는 탭이 닫히거나 다른 주소로 이동하면 녹음과 오프스크린 문서를 정리해야 합니다. 이를 감지하기 위해 탭 이벤트를 구독하고, 캡처에 함께 남길 강의 페이지 제목과 주소를 읽습니다. 열람 기록을 수집하거나 전송하지 않습니다.
```

**scripting**
```
현재 탭에서 재생 중인 <video> 요소의 화면상 위치와 재생 시간을 읽어 (1) 화면 캡처를 영상 영역으로 잘라내고, (2) 캡처에 재생 위치를 함께 기록하며, (3) 사용자가 켰을 때 영상 위에 자막 오버레이를 표시하기 위해 사용합니다. 페이지 내용을 수집하거나 전송하지 않습니다.
```

**host_permissions (http://*/*, https://*/*)**
```
강의는 특정 사이트에 한정되지 않으므로, 사용자가 보고 있는 어떤 강의 페이지에서든 (1) 재생 중인 영상의 화면상 위치를 확인하고 (2) 사용자가 요청한 순간의 화면을 캡처하려면 넓은 호스트 접근이 필요합니다. 두 동작 모두 사용자가 버튼을 눌렀을 때만 수행되며, 페이지 내용을 읽어 저장하거나 외부로 전송하지 않습니다. 자동으로 실행되는 콘텐츠 스크립트는 없습니다.
```

## 4. 심사에서 자주 걸리는 지점 (미리 대비)

| 지점 | 대비 |
| --- | --- |
| 넓은 host_permissions | 위 사유문을 그대로 사용. "콘텐츠 스크립트를 자동 주입하지 않는다"는 문장이 핵심입니다. |
| 개인정보처리방침 없음 | 반드시 공개 URL 을 넣어야 합니다. 비워 두면 자동 거절됩니다. |
| 설명과 기능 불일치 | 스크린샷 4장이 설명의 각 문단과 1:1로 대응되게 찍습니다. |
| 스크린샷 크기 | 1280x800 또는 640x400 만 허용됩니다. |
| 이름 중복 | "SideNote" 가 이미 있으면 대시보드가 저장 단계에서 알려줍니다. 그때 "SideNote - 강의 노트" 같은 형태로 조정합니다. |
| 심사자가 구버전 Chrome 으로 열어 기능이 죽어 보임 | `minimum_chrome_version: 139` 로 막아 뒀습니다. on-device 음성인식(`SpeechRecognition.available/install`, `processLocally`)이 Chrome 139 부터라, 그 아래에서는 설치 자체가 제공되지 않습니다. |
| 쓰지 않는 권한 선언 | 매니페스트에는 위에 사유를 적은 7개 권한만 있습니다. `npm run release:chrome` 이 ZIP 을 만들 때마다 그 목록과 대조해, 설명에 없는 권한이 하나라도 들어가면 FAIL 로 막습니다. |
